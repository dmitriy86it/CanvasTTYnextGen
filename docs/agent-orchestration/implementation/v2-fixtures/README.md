# Фикстуры журнала v2 (редакция 5i, проект)

Примеры журналов формата [v2](../journal-v2-format.md) в раскладке профиля: `runs/<runId>/journal.jsonl` и
`runs/<runId>/texts/<sha256>`. Цепочка хешей и канонический JSON — те же функции, что у приложения (`canonical`,
`sha256Hex` из `journal.ts`). Имя фикстуры — в `runs/<runId>/FIXTURE`.

```sh
node docs/agent-orchestration/implementation/v2-fixtures/build.mjs           # пересобрать (детерминированно)
node docs/agent-orchestration/implementation/v2-fixtures/build.mjs --check   # прочитать читателем A0 этого дерева
```

`--check` только читает. Он прогоняет каждую фикстуру через `parseJournal` и `newerGoal` (код A0, тот же, что в
сборке 1.5.7) в трёх вариантах:
- как записана (`minReaderVersion: 2`);
- в памяти с `minReaderVersion: 1`;
- в памяти с `minReaderVersion: 1` и `skippable: true` у новых видов записей.

Второй и третий варианты формат не пишет никогда. Они показывают, что сделала бы 1.5.7, если бы v2 объявил
совместимость.

Фикстуры описывают формат, а не поведение будущего кода. Второй этап разбора v2 (номера, `applied`, функция
завершения) здесь не исполняется: читателя v2 ещё нет. Правильность по 5i проверяется ревью (§9 формата).

Вывод для §3 формата:
- Откат показа при `minReaderVersion: 1` случаен: он зависит от того, дошёл ли запуск до записи, которую v1 отвергает.
- До неё 1.5.7 показывала бы состояние v1 без решений v2. Пример — фикстура 01 с `skippable` до строки 14: «идёт», без
  предложения команд и без отметки, что проверок не будет.
- `minReaderVersion: 2` даёт один предсказуемый показ на всём протяжении запуска.

## Ожидаемый показ

**В 1.5.7 (A0, режим §2.2)** у всех восьми одинаково:
- в списке: «Более новая версия», причина «создан более новой версией Raoden Loom», цель из таблицы ниже;
- в панели: подсказка «Эта версия показывает только цель и записи журнала…» и сырые записи с проверенной цепочкой;
- состояния, этапов, проверок, замечаний и итога нет;
- действия: только «Отпустить связь» (§2.2.1 п. 1);
- `openRun`, recovery, усечение хвоста, Stop и удаление отказывают (`run_newer_version`).
