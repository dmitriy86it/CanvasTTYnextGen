# Матрица проверок: оркестрация «Лид → Исполнитель»

Ревизия 6 (2026-09-22; раздел исправлений Р3 — 2026-09-23; реальная серия Р6 — 2026-09-24, 11 модельных вызовов, Claude Code 2.1.281, codex-cli 0.155.1). Среда локальных экспериментов (0A и перепроверки ревизии 3): macOS arm64, Darwin 27.0.0, git 2.50.1 (Apple Git-155), node 26.8.1, Electron 43.2.0 из `node_modules` проекта, codex-cli 0.155.1, Claude Code 2.1.278. Реальные запросы к моделям — только пробы 0B ревизии 6 (раздел «Реальные пробы 0B»): 5 запусков CLI в двух разрешённых сериях. Разделы до ревизии 6 — без запуска кода проекта; Р1 и Р2 — тесты проекта (`npm test`), без модельных запросов.

Результат — четыре разных вида основания, не смешиваются:
- **L** — проверено экспериментом на этой машине (с указанием, что именно запускалось); **L✗** — опровергнуто экспериментом;
- **R** — установлено чтением кода, бинарника или конфигурации без запуска; **S** — чтение исходников Codex `rust-v0.155.1` (вид R);
- **D** — описано документацией или `--help`, не проверено;
- **H** — гипотеза, не проверено.

Проверка runner (SB) не доказывает изоляцию Claude Code или Codex, и наоборот: у них разные механизмы (§3.1 и §4 ARCHITECTURE-PROPOSAL).

Воспроизведение: `docs/agent-orchestration/experiments/processes/README.md` (P) и `docs/agent-orchestration/experiments/permissions/README.md` (G — git, SB — Seatbelt). Звёздочкой отмечены эксперименты, которые lead повторил независимо.
