## Окружение

- **Приложение** — упакованная сборка Р10 `<pkg>/release/mac-arm64/CanvasTTY.app`, та, что прошла ревью Р10. Запуск с временным `--user-data-dir`.
  - Установленное приложение, `release/` и проекты пользователя не использовались и не менялись.
  - `HOME` настоящий: CLI использовали существующую авторизацию, её содержимое не читалось и не копировалось.
- **Версии CLI**, проверены `--version` до первого модельного запроса:
  - `codex-cli 0.155.1`;
  - `2.1.281 (Claude Code)`.
- **Модели** по данным самих CLI:
  - лид — Codex `gpt-6-astra` (`turn_context` в сессии Codex), reasoning high, `structured-readonly`;
  - исполнитель — Claude `claude-sonnet-5` (`modelUsage` в сессии Claude), `structured-edit`, `--max-budget-usd 1` на ход.
- **Проект** — новый временный Git-репозиторий `<tmp>/project`: копия `series-project`, один коммит на `main`, пустая папка `node_modules` (игнорируется git).
- **Драйвер** — `scripts/real-ui-series.mjs --real --app <.app>`.
  - Все действия пользователя — события мыши в окне через DevTools-протокол, как в E2E: карточки из контекстного меню, связь портом, диалог цели с лимитами, «Стоп», «Открыть запуск», «Продолжить».
  - Журнал, процессы и git только читались.
  - До серии тот же сценарий прошёл на dev-сборке с тестовыми CLI (`--rehearse`): 27/27 (`rehearsal/`).

- **R1:** `plan → execute → check(passed) → review → checkpoint(1) → final_review → completed`.

  - до выхода: `plan → execute (Claude)`, затем `turn.finished(stopped)`, `paused(user_request)`;
  - после перезапуска и «Продолжить»: `execute → check(passed) → review → checkpoint(1) → final_review → completed`.

**Свидетельство реального старта CLI до вмешательства:**
- **R2:** процесс `~/.local/bin/claude -p --output-format stream-json …`, pid 98246, в дереве main через 0,19 с после `turn.intent`. Ход ещё не завершён. «Стоп» нажат сразу после этого. `turn.finished(stopped)` записан после `command.received(stop)`: ход остановлен именно им, сценарий засчитан.
- **R3:** процесс `~/.local/bin/claude …`, pid 99647, через 0,42 с после `turn.intent`. Выход сделан сразу после этого; ход завершился `stopped` из-за выхода.

**Stop (R2):**
- за 60 с после принятого Stop нет ни одной записи `orch.turn`, `turn.intent`, `check.started`;
- pid Claude мёртв;
- под main не осталось ни supervisor, ни CLI.

**Штатный выход и перезапуск (R3):**
- **Выход** — SIGTERM процессу main. Electron обрабатывает его как `app.quit()`: тот же `before-quit` и остановка сервисов, что у «Quit»/Cmd+Q (меню синтетическими событиями DevTools недоступно). **Cmd+Q и «Quit» отдельно не проверялись.** Приложение вышло за 0,7 с с кодом 0, все 7 его процессов завершились.
- **Состояние после выхода** — `paused(user_request)`, аварийного `outcome_unknown` нет.
- **После перезапуска:**
  - карточки, связь и список run совпадают с состоянием до выхода, история на панели;
  - за 60 с журнал не вырос, процессов оркестрации нет;
  - панель показывает «Пауза — по запросу пользователя» с «Продолжить», «Один шаг», «Стоп».
- **«Продолжить»** начал новый ход исполнителя и довёл run до `completed`.

**Очистка:** в конце серии штатный выход с кодом 0, ни одного процесса приложения не осталось.

## Наблюдения (не дефекты серии; сохранены как ограничения MVP)

- **Следы вне временного `userData`.** Реальные CLI пишут свои сессии в домашний каталог пользователя:
  - Claude — транскрипты в `~/.claude/projects/<путь рабочей копии>/`;
  - Codex — rollout-файлы в `~/.codex/sessions/`.
  
  Приложение это не ограничивает. Стоимость и токены выше взяты оттуда.
- **`codex app-server`** под main — штатное чтение лимитов на HOME (LimitsService). Оно идёт при каждом запуске приложения и к оркестрации не относится. Драйвер исключает его из процессов запуска.
- **Checkpoint без UI.** Интерфейс не показывает имена checkpoint-ссылок, результат забирается git-командами (ARCHITECTURE, «Как забрать изменения»). Известное ограничение MVP.
