# Реальная серия этапа 13: N и L (2026-09-25)

Одна серия, два сценария, установленные CLI с текущей авторизацией пользователя. Каждое действие — событие мыши
в окне приложения через DevTools-протокол. Скрипт: `scripts/real-autopilot-series.mjs --real`; перед ней
прошла репетиция `--rehearse` на поддельных CLI.

## Находки серии

- **F-1 (minor, открыто).** У Laravel-скелета нет `package-lock.json`, и профиль предлагает шаг `npm install`. Этот шаг
  не нужен для `php artisan test`: 12 с загрузки, в папке проекта появляется `package-lock.json`. Панель
  показывает его среди изменений папки. В коммит он бы не попал (LC-10), но это правка пользовательского
  проекта вне lock-файла.
- **Харнесс.** Первая версия отчёта читала факты сессий из поля `data`, а не `detail`. Скрипт исправлен после
  серии, факты извлечены из файла активности в `activity-facts.json`. Повторного запуска не было.
