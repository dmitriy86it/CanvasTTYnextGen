# S7: ручная сверка с терминалом

Автоматическая часть S7 спрашивает CLI через тот же протокол, что и приложение. Поэтому она не доказывает, что приложение видит то же, что интерактивный терминал. Это проверяет только человек. Сверка занимает около 10 минут, моделям ничего не отправляется.

**Не присылайте** конфиги целиком, токены, переменные окружения, адреса серверов и необработанный вывод команд. Нужны только имена, состояния и ваша оценка.

## Подготовка

1. Выберите одну обычную папку своего проекта. Все шаги делайте в ней.
2. Проверьте версии в терминале: `claude --version` и `codex --version`. Они должны совпадать с версиями, которые показывает приложение (сейчас проверены `2.1.283` и `0.155.1`). Если версии другие, остановитесь и сообщите номера версий.
3. В приложении откройте эту папку: связь агентов → «Новая цель» → «Настройки проекта» → «Дополнительно» → «Проверить окружение».
4. В терминале в той же папке запустите `claude`, затем отдельно `codex`. Сообщений модели не отправляйте, только слеш-команды ниже.

`claude mcp list` не запускайте: он печатает учётные данные серверов.

## Что сравнить

Для каждого пункта ответьте одним из трёх вариантов:
- **совпадает**;
- **различается**: что именно, только имена или состояния;
- **не подтверждено**: одна из сторон этого не показывает.

| # | Пункт | В приложении | В терминале |
|---|---|---|---|
| 1 | MCP Claude: имена серверов | «MCP-серверы» в блоке Claude | `/mcp` |
| 2 | MCP Claude: состояние каждого сервера (connected, failed, needs-auth, pending) | в скобках после имени | `/mcp` |
| 3 | MCP Codex: имена серверов | «MCP-серверы» в блоке Codex | `/mcp` |
| 4 | MCP Codex: подключение | Приложение пишет «Подключение не проверено»: без треда Codex этого не сообщает. `вход: unsupported` означает только, что у сервера нет входа. Это **не** признак подключения | `/mcp`. Если терминал показывает подключение, а приложение нет, ответ «не подтверждено» |
| 5 | Скилы Claude | «не подтверждено»: проба их не спрашивает | `/skills`, если есть в вашей версии. Ответ: «не подтверждено» или список имён, который вы видите только в терминале |
| 6 | Скилы Codex | «Скилы»: найдено и включено | `/skills`, если есть в вашей версии |
| 7 | Плагины Codex | «Плагины» | `/plugins`, если есть в вашей версии |
| 8 | Хуки Codex | «Хуки»: найдено и включено | если терминал их не показывает — «не подтверждено» |
| 9 | Права Codex: approval и sandbox | «Политика подтверждений», «Песочница» | `/status` |
| 10 | Модель Codex | «Модель» | `/status` |
| 11 | Права Claude | приложение сообщает режим только в рабочем запуске, здесь «не подтверждено» | `/permissions` или строка режима внизу окна |
| 12 | Одобрение MCP-серверов проекта Claude | приложение запускает `claude -p`. В S4 сервер из `.mcp.json` там подключался без одобрения | Интерактивный режим может спросить одобрение («Pending approval»). Отметьте, спросил ли |

## Как прислать итог

Двенадцать строк вида `N: совпадает | различается: … | не подтверждено`. К ним версии CLI и одно слово о папке (например, «рабочий проект на Laravel»), без пути.

## Как засчитывается

- S7 засчитывается, только если по MCP (пункты 1–4) нет «различается».
- «Не подтверждено» допустимо, но записывается как ограничение.
- Паритет с терминалом не объявляется даже при полном совпадении. Сверка покрывает только то, что CLI сами показывают, и только в этой папке.
