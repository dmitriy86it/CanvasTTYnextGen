# Независимое ревью рабочих пространств (2026-09-28)

Контракт: [workspaces-spec.md](../../implementation/workspaces-spec.md). Приёмка этим документом не объявляется.

## Как было организовано

Участники — субагенты одной сессии Claude Code (Agent tool с именованными агентами). Владельцы файлов назначены
заранее и не пересекаются:

| Участник | Роль | Пишет только в |
|---|---|---|
| reviewer-main | проверяющий: main, данные, миграция, владение | `repros/main/` |
| reviewer-ui | проверяющий: renderer, камера, жесты, закрытие, виджет, Browser, smoke | `repros/ui/` |
| fixer-main | исправления main | `WorkspaceStore.ts`, `canvasStore.ts`, `manager.ts`, `shared/orchestration.ts`, одна строка в `index.ts`, свои тесты |
| fixer-ui | исправления renderer | `App.tsx`, `WorkspaceCanvas.tsx`, `CanvasMinimap.tsx`, `workspaceModel.ts`, `OrchestrationDialogs.tsx`, `useOrchestration.ts`, `app.css`, `i18n.ts`, `scripts/smoke-orchestration-ui.mjs`, свои тесты |
| координатор | исходное состояние, независимые прогоны, документы | `baseline/`, `runs/`, отчёты |

**Правила:**
- проверяющие не правят код, исправители не правят репро;
- репро после первого запуска не меняются, ошибочные сохранены рядом с `-v2`;
- каждое репро координатор запускал сам, до и после исправлений.

Отчёты проверяющих пришли сообщениями, координатор сохранил их без смысловых изменений:
[repros/main/REPORT.md](repros/main/REPORT.md), [repros/ui/REPORT.md](repros/ui/REPORT.md).

**Как исправлено:**
- **R-M01, R-M02:** файл принимается, только если верна каждая запись. Иначе он отодвигается как `.damaged-<uuid>`,
  миграция повторяется.
- **R-M03:** сравниваются действующие пространства, а не сырые id; скрытое известное пространство не считается общим.
- **R-M05:**
  - main отдаёт `runId`, `workspaceId` и `runReadable` в отказе `folder_busy` и в готовности;
  - интерфейс показывает «папка занята в пространстве X · Открыть X» по ответу main;
  - прежняя реконструкция по снимкам удалена;
  - путь гонки при самом старте проверен R-U09.
- **R-U03:** владелец Browser берётся из текущей карточки при любом изменении границ.
- **R-U01:** жест миникарты отменяется при переключении пространства.
- **R-U02, R-U07 и `bringBrowserHere`:** камера применяется только к пространству, запомненному в начале действия, а
  для чужой карточки плагина сначала выполняется переход в её пространство.
- **R-U04:** `overflow: clip` у `html`, `body`, `#root`, `.workspace`.
- **R-U06:** превью области сбрасывается при переключении.
- **R-U05:** shell-терминалы не считаются работой при закрытии. Незавершённый запуск (в том числе на паузе) и живой
  CLI считаются, как раньше.

**Проверки, которые держатся** (новые репро): R-U08 — перетаскивание терминала и заметки, прерванное ⌘цифрой; R-U09 —

## Нестабильность перетаскивания и `outside the window` (`smoke-orchestration-ui`)

Первый упавший прогон — `runs/first-failing-orch-ui-p2b/`: оба симптома, лог наблюдателя DevTools. Он воспроизведён
при двух параллельных smoke; поодиночке прогоны зелёные.

- **`outside the window` — причина установлена.** Smoke вызывал `focus()` без `preventScroll` на элементе вне окна.
  Это прокручивало `.workspace`, и надстройки рисовались со сдвигом. У пользователя тот же механизм срабатывает от Tab
  (R-U04).
  - Исправление в приложении: `overflow: clip` (R-U04).
  - Исправление в smoke: `focus({preventScroll: true})`.
- **Перетаскивание заголовка — причина установлена частично.**
  - **p2b:** точка нажатия бралась по центру элемента без проверки попадания и оказалась вне окна. Теперь smoke жмёт в
    точку, подтверждённую hit-test, а успех проверяет по позиции карточки, сохранённой в main.
  - **p9b:** нажатие попало в заголовок, но позиция не изменилась. **Причина не установлена**: 16 прогонов с полным
    логом захвата указателя не упали. Потеря фокуса окна обрывает панорамирование (штатная отмена жеста) и меняет
    раскладку.
  - Повторы и ключи Chromium не добавлялись.

## Не проверено

- **Перекрытое окно:** надёжного способа перекрыть окно, не трогая рабочий стол пользователя, нет. Свёрнутое окно
  проверено `smoke-workspaces-background`; за перекрытое оно не выдаётся.
- **Свёрнутое окно:** для новых репро не проверялось.
- **Частичный сбой «Остановить и скрыть»:** без правки кода его не вызвать; проверено только по коду.
- **SIGWINCH:** при каждом возврате в пространство xterm шлёт `terminal.resize`, то есть CLI получает SIGWINCH.
- **Интерфейс `folder_busy`:** ветка `runReadable: false` и владелец, неизвестный окну.
- **`overflow: clip`:** побочные эффекты для панелей со своей прокруткой проверены только по CSS.
- **Две гонки с удалением пространства** (терминал без `workspaceId`, сохранение настроек): только по коду, карточка
  не теряется, попадает в «Общий холст».

## Оставшиеся ограничения и наблюдения

- **Причины p9b и «Бета2» не установлены.**
- **«Остановить и скрыть»** завершает и shell-терминалы, если диалог открыт из-за запуска. Это соответствует букве §5
  («завершение каждого терминала») и не менялось.
- **Нечитаемый запуск** (без снимка в renderer) при закрытии работой не считается, как и до ревью.
- **Откат `canvas.json`** контрактом не заявляется (§3).
