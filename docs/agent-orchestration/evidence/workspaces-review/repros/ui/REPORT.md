# reviewer-ui: отчёт независимого ревью (renderer, камера, жесты, закрытие, виджет, Browser)

Дата: 2026-09-28. Отчёт пришёл сообщениями, координатор сохранил его без смысловых изменений.

Условия прогонов: Electron 1280×800, без ключей Chromium, временные userData, HOME и SHELL, тестовые CLI. Каждое репро
завершается кодом 0, если всё в порядке, и кодом 1 при дефекте. Первые версии двух репро с ошибками сохранены рядом с
исправленными `-v2`.

## 2. Нестабильность перетаскивания и `outside the window` (smoke-orchestration-ui)

**Откуда сообщение.** Его выдают `reveal()` и `pointOn()` в `scripts/orchestration-app-kit.mjs`.

**Как искали.** Smoke не менялся, порт был закреплён. Параллельно работал пассивный наблюдатель DevTools, который
записывал:
- прокрутку;
- вызовы `focus()` и `scrollIntoView()` со стеком;
- события указателя с попаданием;
- камеру, blur и focus окна.

**Статистика.**
- Поодиночке 6 из 6 прогонов зелёные.
- Два smoke параллельно: 3 падения из 36 (p2b, p4a, p9b).
- Все 16 прогонов с полным логом захвата указателя зелёные.

**Первый упавший прогон** — `scratchpad/wsr/reviewer-ui/orch-par/p2b/log.txt`, копия в `first-failing-p2b-keep/`.

1. **`outside the window` — причина установлена.** Smoke сам вызывает `.agent-card__port.focus()` без `preventScroll`.
   Порт был вне окна, и `.workspace.scrollLeft` изменился с 0 на 978. Назад прокрутку ничто не возвращает, поэтому
   надстройки рисуются со сдвигом, и `reveal()` бросает ошибку. У пользователя тот же механизм срабатывает от Tab
   (R-U04).
2. **Неудачное перетаскивание заголовка — причина установлена частично.**
   - **p2b.** Нажатие пришлось в точку вне окна: `app.center()` берёт центр элемента без проверки попадания, а камера
     к тому моменту ушла вправо.
   - **p9b.**
     - Панорамирование прервалось на blur окна: запустилось соседнее окно, и сработал штатный
       `cancelPointerGesture`.
     - Раскладка изменилась.
     - Нажатие точно попало в заголовок, но позиция карточки не изменилась.
     - Исключены: прилипание, отказ main, промах, нативный drag картинки, прокрутка.
     - **Причина не установлена.** Гипотезы: потеря захвата указателя или `pointermove` без фокуса окна.

## 3. Что держится (по коду)

- **Переключение ничего не пересоздаёт.**
  - `WorkspaceCanvas` не размонтируется.
  - Подписки на запуски не зависят от активного пространства.
  - Скрытые терминалы восстанавливают вывод через `readBuffer`.
  - Не проверено: при каждом возврате xterm шлёт `terminal.resize`, то есть CLI получает SIGWINCH.
- **Жесты холста.** Колесо, ждущее кадра, pan указателем, рамка и перенос группы отменяются при смене пространства.
  Изменения камеры помечаются пространством. Исключения — R-U01, R-U02 и R-U06.
- **Сохранение камеры.** Запись камеры адресована своему пространству, переключение и выгрузка страницы сбрасывают
  отложенную запись.
- **Владение новых карточек.** Новые карточки получают `workspaceId` при создании, перенос его сохраняет (кроме
  Browser, R-U03).
- **Перенос группы с незавершённым запуском** блокируется в UI и в main.
- **Удаление из UI** без каскада.
- **Закрытие.**
  - «Скрыть» ничего не останавливает.
  - «Остановить и скрыть» показывает строку по каждому участнику.
  - При появлении новой работы пространство не скрывается.
  - Мелочи: у строки «останавливается» нет «Открыть»; новая работа распознаётся, только если запуск уже есть в
    состоянии renderer.
- **Виджет** открывает нужное пространство и панель. Счётчики вкладок строятся из тех же строк, что и виджет.
- **folder_busy в UI.** Подсказка «Папка занята в пространстве X» с «Открыть X» строится в renderer до старта.
  Ограничения:
  - сравнение строкой, а не realpath;
  - видны только последние запуски связей;
  - при отказе main без подсказки остаётся общий текст (это R-M05).

## 4. Не проверено

- **Перекрытое окно:** нет надёжного способа перекрыть окно, не трогая рабочий стол пользователя. Свёрнутое окно за
  перекрытое не выдаётся.
- **Свёрнутое окно для своих репро:** не проверялось. Smoke рабочих пространств не запускался: их порты вне
  разрешённого диапазона.
- **Ключи Chromium в `smoke-workspaces-ui.mjs`:** `--disable-backgrounding-occluded-windows`,
  `--disable-renderer-backgrounding`, `--disable-background-timer-throttling`. Все утверждения W1–W10 получены с ними.
  - **Дополнение координатора:** копия smoke без этих ключей прошла без ошибок в обычном окне
    (`../../baseline/nopaint-smoke-ui.log`).
- **Частичный сбой «Остановить и скрыть»:** без правки кода его не вызвать.
- **Согласованность «!»** сверялась только по коду.
