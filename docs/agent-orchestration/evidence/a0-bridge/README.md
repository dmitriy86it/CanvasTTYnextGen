# A0: мост совместимости с журналом более новой версии — доказательства

Дата: 2026-09-30. Контракт: [acceptance-review-spec](../../implementation/acceptance-review-spec.md) §2.2, §5 (A0),
§7 п. 17. Статус: реализовано, ждёт внешнего ревью A0; не принято. A1–A4 не начаты. Всё — на временных профилях и
поддельных CLI; пользовательские профили, реальные модели и установленное приложение не использовались; упаковки,
установки, commit и push не было.

## Что сделано

- `journal.ts`: журнал, первая строка которого несёт целое `v` больше поддерживаемого (сейчас 1), — `integrity:
  "newer_version"` с версией и состоянием цепочки (`ok` / `torn_tail` / `corrupt`). Проверяются только конверт записи и
  цепочка хешей (seq, prevHash, hash, runId, одна версия), `applyRecord` не вызывается, `state: null`. Первая строка без
  `\n` тоже распознаётся; оборванная посреди JSON — остаётся `corrupt` (версию не прочитать).
- `store.ts`: `openRun` отказывает `journal_newer_version` **до** захвата блокировки (каталог запуска не меняется), также
  с `acceptTornTail`; журнал больше 64 МиБ распознаётся по первым 64 КиБ.
- `manager.ts`: снимок только для чтения (`paused`, причина `newer_version`, `view.newer` с целью из `run.created`),
  история — записи проверенного префикса. Команды, `changes`, `diff`, `create` с тем же id отказывают
  `run_newer_version` до открытия, runtime и CLI. Связь с таким запуском остаётся занятой (fail-closed, как до A0),
  но отказ называется `link_newer_run`, а не «остановите запуск»; резерв `startOnLink` с его id снимается.
- Renderer: панель запуска новой версии — плашка, цель, сырые записи, только «Закрыть»; журнал таких запусков не
  интерпретируется; диалог закрытия пространства не считает его работой и не шлёт stop.
- Новые запуски по-прежнему пишутся в v1 (`buildRecord`).

## Независимое ревью

Отдельный участник без правок кода, собственный скрипт на временном профиле: 10 искусственных журналов (v2, v42,
битый хеш, оборванный хвост, v2+v1, v2+v3, изменённый и неполный текст цели, первая строка без `\n`, больше 64 МиБ),
все виды команд через IPC-обработчики, повторное открытие новым менеджером, соседний v1 до `completed`. Отпечатки
(sha256, размер, режим, mtime) 30 файлов равны на всех этапах; файлов с их id вне `runs/` нет. Первый прогон 43/47,
найдено R1–R4 и N1–N2; все исправлены, итоговый прогон 48/48.

| Id | Уровень | Суть | Итог |
|---|---|---|---|
| R1 | blocking | связь и папка навсегда заняты, UI просит «остановить» то, что остановить нельзя | отказ `link_newer_run` с объяснением; занятость сохранена сознательно — **решение на внешнее ревью** |
| R2 | blocking | «Остановить и скрыть» слал stop запуску новой версии | не считается работой пространства |
| R3 | wish | первая строка без `\n` и журнал > 64 МиБ считались повреждением, `openRun` создавал locks; `create` вызывал CLI | распознаются; отказ до блокировки и до runtime |
| R4 | wish | `startOnLink` с id такого запуска оставлял резерв в `canvas.json` | резерв снимается |
| N1 | wish | для журнала > 64 МиБ пустые цель и история, файл читался целиком | читаются первые 64 КиБ |
| N2 | wish | поведение оборванной посреди JSON первой строки не зафиксировано | комментарий и тест |
