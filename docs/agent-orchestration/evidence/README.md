# Доказательства оркестрации

Бинарные доказательства (снимки экрана png и другие изображения, видео, файлы больше 1 МБ) хранятся вне git.
Их суммы sha256 и размеры — в [BINARY-MANIFEST.sha256](BINARY-MANIFEST.sha256) (формат: `sha256  путь  размер`).
Текстовые доказательства, включая журналы `*.log`, лежат в подкаталогах. Пять журналов с локальными путями
пользователя тоже хранятся вне git; их суммы — в том же манифесте.
