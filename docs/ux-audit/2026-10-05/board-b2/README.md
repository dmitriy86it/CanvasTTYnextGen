# Доска задач на холсте (B2)

Код — ветка `feat/b2-board-ui`, план — `docs/agent-orchestration/implementation/stage-b-board.md` §6 и §8 B2. Снимки — из smoke `board-ui`:
- подставные CLI, временный Git-проект, окно 1280×800;
- холст в масштабе 0,5. Файлы `*-board.png` — та же доска крупно: вырезка по её рамке, масштаб 2.

PNG в git нет; суммы и размеры — в `BINARY-MANIFEST.sha256`.

## Снимки

- `board-01-empty` — кнопка «Доска» в шапке пространства ставит доску на свободное место холста.
  - Колонки: «Очередь / Работа / Проверка / Готово».
  - Подсказка: чем задача отличается от цели.
- `board-02-new-task-form` — форма «Новая задача».
  - Поля: название, что сделать, «Как понять, что готово», папка проекта, «Выполнять после».
  - Пока поля не заполнены, форма говорит, чего не хватает.
- `board-03-three-tasks` — три задачи. T-3 «Ждёт T-2», у неё нет «Запустить».
- `board-04-goal-dialog-from-task` — «Запустить» открывает диалог цели: первой строкой «Задача с доски: T-1 · …», текст и требования задачи уже подставлены. Запуск несёт `goal.task`.
- `board-05a-waits-permission` — у T-2 запрос исполнителя.
  - На доске: «Ждёт разрешения: ls src» и «Ответить на запрос»; кнопка открывает панель запуска, где отвечают на запросы.
  - Карточка агента в работе показывает «T-2 · Модуль two».
  - T-1 — «Готово — подтверждено проверками», зелёная галочка.
- `board-05-completed-without-checks` — T-2 в «Проверке».
  - Строка: «Завершено без проверок: команды проверки не заданы и не запускались…».
  - Выполненные условия помечены «по отметкам агентов».
- `board-06-accept-explained` — «Принять результат» сначала объясняет: «Команды проверки не запускались… Дальше пойдут: T-3». Пока вопрос открыт, остальные кнопки задачи скрыты.
- `board-07-done-confirmed-and-accepted` — оба вида «Готово» рядом.
  - T-2 — «Готово (принято вами, без проверок)», свой значок и пунктирная граница, не зелёная галочка.
  - T-3 больше не ждёт.
- `board-08-after-reload` — после перезагрузки окна те же колонки, причины и отметки. Ни один CLI не запустился заново.
