# UX-аудит Raoden Loom 1.5.9 — 2026-10-05

Только документ: код приложения не менялся. Снимки сделаны на сборке 1.5.9 (код приложения = `main` 258ae9a) с подставными CLI в
герметичном режиме. Реальных моделей не было.

- `novice-flows.md`, `novice-pauses.md` — ответы «новичка» по каждому экрану, дословно.
- `shots/` — 160 скриншотов. В git их нет (`.gitignore`), их суммы и размеры — в `BINARY-MANIFEST.sha256`.
- `pause-gallery.json` — что показали панель, ярлык связи и карточки для каждой причины паузы.
- `scripts/ux-pause-gallery.mjs` — как снята галерея пауз и экраны настроек; повторяется одной командой.

## 1. Как снято

| Группа | Откуда | Что на снимках |
|---|---|---|
| Первый запуск, карточки, связь | `smoke-orchestration-ui`, `smoke-native-ui` | пустой холст, карточки лида и исполнителя, отказ связи между проектами, удаление |
| Настройки проекта и диалог цели | `smoke-autopilot-ui`, `smoke-v2-checks-ui`, галерея (`shots/settings/`) | права, модели ролей, команды проверки, проверка окружения, готовность (Laravel), модель недоступна |
| Ход запуска | `smoke-native-ui`, `smoke-autopilot-ui`, `smoke-orchestration-ui` | запрос разрешения, вопрос агента, форма MCP, план, исполнитель работает, стоп |
| Вкладки панели | все smoke | Итог (обычный, развёрнутый, после ошибки загрузки), Обзор, Действия (по ролям), Изменения, История |
| Итоги | `smoke-v2-checks-ui`, `smoke-activity-ui`, `smoke-orchestration-ui` | подтверждено, «Завершён без проверок», остановлен, решения человека (спорный пункт, понижение, снятие условий, push и QA) |
| Все 27 причин паузы журнала | `ux-pause-gallery.mjs` (`shots/pauses/`) | холст (ярлык, карточки, виджет «Ждёт вас»), панель, вкладка «Действия» |
| Ошибки окружения | галерея, `smoke-native-ui`, `smoke-v2-checks-ui` | CLI не найден (виджет Home), модель недоступна, песочница недоступна, проверке нужно больше прав |

Ограничения съёмки:
- **Галерея пауз меняет только причину** в последней записи `run.status` настоящего запуска. Поэтому заголовок, шаг
  «Дальше», ярлык и карточки — настоящие для каждой причины. А то, что берётся из других записей журнала (вопрос
  агента, предложенные команды, спорное замечание, предложение плана, решение о push и QA), в галерее не показано.
  Эти экраны с настоящими данными есть в `shots/v2-checks-ui/` (v2-03, v2-08, v2-12, v2-14), `native-ui/05` и
  `autopilot-ui/05–07`. Поэтому замечание новичка «во всех паузах с выбором есть только „Стоп“» отчасти вызвано
  самой галереей. Подтверждённая часть — в находках Н2 и Н9.
- `prepare_failed`, `model_unsupported` и лимит провайдера — уточнения `environment_error`. Они выводятся из ленты и в
  галерее не показаны.
- В герметичном режиме виджет Home пишет «CLI не найден» у всех провайдеров. У пользователя с установленными CLI
  первый экран выглядит иначе.
- Новичок отметил повторы снимков: `settings-2` совпадает с `settings-1` (прокрутка не сработала), `native-ui/08`
  совпадает с `07`, `v2-06` — с `v2-05`.

## 2. «Новичок»

Участник не читал код и документацию, видел только скриншоты. По каждому экрану он ответил: что произошло, что
сделать, какая кнопка главная, какие слова непонятны. Ответы дословно — в `novice-flows.md` (76 экранов) и
`novice-pauses.md` (27 пауз, с оценкой ясности 1–5).

**Самые непонятные экраны** (его слова, сокращено):
1. `v2-checks-ui/v2-02` — «Завершён», рядом красное «Команды проверки не запускались» и «node --test passes —
   выполнено» с доказательством «файл существует». «Сделана работа или нет и можно ли этому верить».
2. `native-ui/02` — «Стена жаргона (TUI, stream-json, -ilc, precmd, submodules), два жёлтых предупреждения; неясно,
   блокируют ли они „Старт“».
3. `v2-checks-ui/v2-10` — «Исчерпан лимит — поднимите лимит ниже»: поле без подписи, «Продолжить» не видно, самая
   заметная кнопка — «Стоп».
4. `v2-checks-ui/v2-12` — предложение снять условие: «WHY-C2», «условие» против «требования», красная плашка, самая
   яркая кнопка «Принять» — «новичок легко согласится выкинуть проверки».
5. `native-ui/01` — первый экран: «шесть строк „CLI не найден“, часы, иконки без подписей, кнопки „начать“ нет».

**Паузы:** понятны (5 из 5) только `user_request` и `recovered`. Хуже всего (1 из 5) — паузы, где нужен выбор, а
также `sandbox_unavailable` и `lead_modified_tree`. Шесть разных ситуаций называются одинаково: «Нужно ваше
решение».

**Слова, непонятные везде:**
- роли и единицы работы: лид, ход, шаг, этап, раунд;
- что считается доказательством: контрольная точка, рабочая копия, рабочее дерево, песочница, служебный git, журнал;
- инструменты: QA, push, CLI, MCP;
- идентификаторы: R1/C1/F1, «Наблюдать», «Отпустить связь», «Цель принята финальным ревью».

## 6. Как разбить на PR

1. **«Паузы понятны»** — №1, №2, №4. Структура текста паузы, тест на полноту, главная кнопка, ярлык и карточки.
   Только renderer и i18n.
2. **«Диалоги и итог»** — №5, №6, №7. Стили контролов, закреплённый низ, «Подробнее», безопасная кнопка в
   предложении плана, итог одной фразой.
3. **«Внимание человека»** — №3 и фильтр «ждут меня». Уведомления, значок Dock (main), настройка «уведомлять».
4. **«Готовность до старта»** — №8 и №9. «Проверить сейчас» (main: самотест, команды на исходном дереве),
   стоимость на табло.
5. **«Результат в проект»** — №10. «Создать ветку в проекте», затем «отдельная копия» по умолчанию для новых
   проектов.

PR 1–3 независимы и небольшие. Каждый можно проверить smoke со снимками до и после, тем же
`ux-pause-gallery.mjs`.
