## Что осталось непонятным

- **«Прошла на исходном коде» рядом с «в папке проекта ничего не запускалось».** «Исходный код» читается как «моя папка». Точнее было бы «на копии исходного кода».
- **Цифры на карточке и на табло.** Карточка лида считает вызовы лида и проверяющего (одна CLI), табло — всех ролей; подписи «этот агент» на карточке нет. Денег нет намеренно.
- **«Старт» активен при командах, падающих до изменений.** Так задумано: это предупреждение, старт блокируют только блокеры. Новичок ждёт, что опасное предупреждение остановит старт.
- **Риск «Как в моём терминале»** на снимке блокера не раскрыт: объяснение появляется после нажатия кнопки (подтверждение), на снимке его нет.
- **Пауза лимита, нижняя часть (итог из PR 2):** общая «Причина» вместо названного лимита, «1 из 1 критериев» рядом с неподтверждёнными требованиями, английские тексты подставного CLI («NOT-FIXED», «the note is explained»), заголовок «Итоговое состояние» у паузы.
