# Карточки агентов: изменяемый размер и живая лента (1.5.13)

Код — ветка `ux/agent-card-resize`. Снимки — из smoke `agent-cards-ui` (подставные CLI, временный Git-проект, окно 1280×800, холст в масштабе 0,5, снимок в пикселях 1:1). PNG в git нет; суммы и размеры — в `BINARY-MANIFEST.sha256`.

- `shots/agent-cards-ui/01-compact.png` — компактные карточки во время хода исполнителя. Лид ждёт: «Codex закончил ход», под ним одна строка «Ждёт: Claude выполняет этап 1: …» вместо дословного повтора. Ни одна строка не обрезана по высоте; длинные заканчиваются «…», полный текст в подсказке.
- `shots/agent-cards-ui/02-expanded.png` — обе карточки увеличены после запуска. В освободившемся месте — последние события своего агента в формате ленты активности, новые внизу.

## Что было (1.5.12)

Тот же smoke на сборке 1.5.12: в компактной карточке строки сжаты до 4 px при нужных 13 — «Вызовы этого агента: 1 · токенов: …», «последнее событие …», «0 из 1 критериев выполнено» обрезаны посреди текста. Строка лида «Claude выполняет этап 1: …» дословно повторяет строку исполнителя.

## Совместимость с 1.5.12

Упакованная 1.5.12 открыла `orchestration/canvas.json` с новым полем `expanded` и с увеличенной карточкой (580×700):
- без ошибок, файл не отложен как повреждённый;
- обе карточки показаны в прежнем компактном размере (1.5.12 рисует один размер);
- её перемещение карточки сохранило `expanded`.

Если в 1.5.12 подвинуть увеличенную карточку, 1.5.12 запишет компактный размер. В 1.5.13 «Развернуть» вернёт запомненный.
